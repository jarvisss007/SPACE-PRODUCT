How the site was checked, what was found, and what was done about it. Every page was opened in a real browser at phone (375 px) and desktop (1,280 px) width, every button was pressed, and every page's facts and checks tables were compared with published sources by independent reviewers.

## A mistake made during the fixes, and how it was caught

68 of the findings came with exact replacement text and were applied automatically. Nine of those replacements contained the reviewer's own editing notes, so applying them literally broke the Milky Way Atlas and Voyager Now scripts, the Spacecraft Archive country list, and left notes visible on three pages. A second set of reviewers spotted it; each was undone and re-applied by hand, and a stricter test that listens for errors while a page loads (before its own code runs) was run on all 59 pages: no errors. That test was itself proven by feeding it a deliberately broken page.
